# F2-02｜占術切替時の編集ページ一覧混在修正

認証付きpreviewで6占術を順に開くと、APIの定義カタログは選択占術だけになるが、左の編集ページ一覧は保存中の全占術ページを表示していた。選択中の固定ページも切替前の占術のまま編集できる状態だった。保存データの混在保持は非破壊保存として必要だが、編集対象としての混入はF2-02を満たさない。

## 修正

編集対象ページをselectedDivinationに絞り、methodKeyなしの共通ページは維持する。現在ページが対象外なら、対象の先頭ページへ移る。対象ページがまだない間は本文なしの読み込み表示にし、対象外本文を出さずタイトル／列追加も保護する。

ページ順変更と「次ページへブロックを移動」も、同じ対象集合の隣接ページを使用する。対象外ページとその本文は保存データから消さず、切替先へ戻ると再び表示する。保存形式と印刷plannerは変更しない（plannerは既に占術別filterを持つ）。

## 検査

実runtimeのcurrent／renderを使う回帰を先に追加。修正前は他占術のdata-pageが一覧へ漏れて失敗。修正後は共通・対象占術だけ、対象外選択の解除、対象内並び替えと隣接移動、対象0件、保存内容保持を検査PASS。全package test／production build／git diff --check PASS。
