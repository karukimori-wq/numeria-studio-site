## 検証と制限

`scripts/verify-f4-result-connections.mjs` は85IDの一致、未接続状態、代表的な計算値、名前の正規化・欠損、うるう日、不正入力、年の切替を検証する。これは実装の回帰検証であり、F4-09の外部計算器との独立照合ではない。

9年周期が西暦1〜9999の範囲から外れる基準年では、周期全体をnullにする。名前の母音または子音が存在しない場合も該当数はnullとし、0を代入しない。

既存の本番計算器には2026年固定とライフパス計算手順の差がある。今回の計算基盤は本番UI・保存スナップショット・確定結果へまだ接続していない。本番の数値表示は変更されない。
