# 四柱の確定固定表と8ページ計算adapter｜2026-11-13

PR #95の統合候補を基点にした追加作業。最新mainへの正式接続完了ではない。

## 採用根拠

[利用者確定84〜86](https://app.notion.com/p/3fee71121fed818d91b7ce187ed14428) のA表を採用する。通変星は五行／陰陽の100組、十二運は長生開始支と陽干順行／陰干逆行、蔵干は本気／中気／余気の明示対応。丑の中気は辛、余気は癸であり、ライブラリ配列順から役割を推測しない。臨官→建禄、七殺→偏官、正印→印綬へ表示を統一する。日柱天干は日主として扱い、比肩の集計対象へ混ぜない。

## 実装範囲

- `four-pillars-fixed-tables.js`: 入力干支検査、通変星、十二運、蔵干の役割付き配置、財星の実在配置（0件を保持）。表面五行は既存6/8文字集計のままで蔵干を加算しない。
- BAZ-04/05/09/10/11に計算データを追加。既存BAZ-01/02/03と合わせ8ページ。時刻不明の三柱は3行、時柱を補わない。必須柱不確定は8ページとも不足扱い。
- 残6ページ（BAZ-06/07/08/12/13/14）は大運／年運／2名比較の未接続理由を維持。
- 正式Result Key、登録原文、素材、確認済みResult、UI保存、Browser/PDFは未接続。全ページ `publicationAllowed:false`、原文承認と素材承認を生成しない。

## 検査

- Notionの明示100組をそのまま期待値にした検査。
- 120組の十二運は固定lunar-typescript対応表との整合検査。独立した命式の正解合格とはしない。
- 蔵干役割、日主除外、財星0件、未知時柱、干支不正、全8ページへの不足伝播、他占術隔離、既存23時台・夏時間の検査。

05および84〜86の正本には、起運の年→月→日→時加算と月末クランプが承認済み86（分未満切捨て）の範囲外にあると明記されている。大運依存ページを埋めるために未確定の暦加算結果を正式値へ昇格しない。固定表の計算整合と、独立命式・大運の検証資料、原文／素材の専門承認は別のゲート。
