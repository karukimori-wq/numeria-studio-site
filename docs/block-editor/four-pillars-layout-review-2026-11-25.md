# 四柱推命 A4組版確認用PDF（ローカル・未承認）

認証済みpreview管理者の架空入力で、BAZ-01〜14のスタンダード36枚とマガジン36枚を収録。表紙・ページ対応表を加え、A4全74ページの確認用資料をローカルoutput/pdfへ作成した。本文は画面画像であり、アプリの正式PDF出力ではない。全ページに未承認・正式発行不可を明記した。

CUAの矩形指定撮影でポインタ混入と一部見出しの描画欠けが発生したため、その収録は破棄し、撮影直前にポインタを紙面外へ移して全画面を取得した。観測済みDOM座標のA4枠をPillowで切り出し、無拡縮・画素修正なしのPNGとして保存。元画面→切り出しPNG→PDF埋込RGB画素の一致を72/72で確認した。全74ページがA4、各ページの未承認表示、画像hash、原文・表・図の改ページ前後一致、本文枠内の高さを検査した。

Popplerで全74ページを再描画し、7枚の一覧画像と表紙・索引・大運表・転機ページの詳細を目視確認。紙面内ポインタ、撮影由来の欠け・重なりは見つからなかった。承認状態のみが残る続頁の大きな空白は現在の下書き画面を保持しており、正式デザイン承認を意味しない。
